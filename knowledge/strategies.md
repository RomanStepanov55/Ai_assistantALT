# Стратегии — Muscle Legends

**Состояние: 2026-11-16.** Здесь только стратегии, которые можно проверить наблюдением. Ни одна не объявляется работающей до измерения.

> Правило: «стало больше силы» ≠ «стратегия лучше». Сравнивать можно только при одинаковых экипировке, бустах, зале и длительности, с указанием погрешности.

## А. Рабочие (проверяемые) гипотезы

| ID | Стратегия | Ожидаемый эффект | Как проверить | Статус |
|---|---|---|---|---|
| S-01 | Держать **одно** упражнение длинными окнами вместо частой смены | Выше прирост/мин за счёт меньших простоев | EXP-02: равные окна A/B | ГИПОТЕЗА |
| S-02 | Тренироваться **без** открытых модалок | Модалки перекрывают HUD и замедляют действия | Сравнить прирост/мин с модалкой и без | ГИПОТЕЗА |
| S-03 | Использовать бусты только когда они **бесплатны и обратимы** | Прирост/мин выше, если буст реально работает | EXP-03 | ГИПОТЕЗА (эффект буста не измерен) |
| S-04 | Не менять зал до выполнения требований следующего | Переходы «в никуда» съедают время | EXP-04 | ГИПОТЕЗА |
| S-05 | Сначала питомец с подтверждённым бонусом, потом всё остальное | Бонус питомца может быть множительным | EXP-05 | ГИПОТЕЗА (бонус питомца не подтверждён) |

## Б. Отвергнутые/запрещённые «стратегии»

## В. Что нужно, чтобы стратегии стали «подтверждёнными»

1. Живые измерения S0/S1 (EXP-01) — базовая линия.
2. Минимум 3 повтора на вариант.
3. Запись в `experiments.csv`: результат, погрешность, ограничения.
4. Только после этого — изменение поведения агента.
