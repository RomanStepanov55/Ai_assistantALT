# Установка Alontito Continual Learning

1. Сделайте резервную копию проекта.
2. Распакуйте содержимое архива в корень проекта с заменой файлов.
3. Установите основные зависимости: `pip install -r requirements_omni.txt`.
4. Убедитесь, что Ollama запущена и модели из `config_omni.json` доступны.
5. Запустите тесты: `python -m unittest discover -s tests`.
6. Запустите приложение обычным способом через `Alontito_Omni.bat`.

## Новые данные

- SQLite память: `data/alontito_memory.sqlite3` и `data/alontito_learning.sqlite3`.
- Одобренные обучающие примеры: `data/curated_training.jsonl`.
- Отчёты регрессионной оценки: `data/evaluations/`.
- LoRA: только вручную, после накопления достаточного количества подтверждённых примеров; см. `training/TRAINING_GUIDE.md`.

Никакие скриншоты не сохраняются в базе как изображения. Хранятся компактные признаки и метаданные. Не удаляйте базу данных, если хотите сохранить накопленный опыт.

## Важно

Критика модели — не доказательство истинности. Для важных фактов подключайте независимые источники или детерминированные проверки. Новый LoRA-адаптер не активируется автоматически: сначала сравните его с baseline на одинаковом отложенном наборе.
