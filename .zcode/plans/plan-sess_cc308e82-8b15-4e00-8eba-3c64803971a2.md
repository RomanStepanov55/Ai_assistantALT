# Alontito 2.0 — агент без Roblox, приложение на любое устройство, разъём под ваш мозг

## Контекст
Проект — автоматизированный ИИ-агент Alontito; Roblox был первой задачей. 24.11 вы сняли игру (юридические риски), но в дереве остались: два места, запускающие Roblox (терминал и `alontito-app/`), драйверы игры, читающая цепочка на них, и необещанное «консультировать и напоминать». Пульт не ставится на телефон.

Задача: убрать Roblox целиком и собрать готовое приложение модели и агента для любых устройств. **Правило по модели (ваше, 27.11): мозг — свой, вы делаете его сами. Никакая сторонняя модель не отвечает пользователю. Скачанная Ollama-модель — только учитель для обучения нашего агента.**

## Мои допущения (вопросы остались без ответа — поправьте при утверждении)
1. Возможности v1: память и консультации; напоминания и расписания; приём текста, голосовых, фото и файлов; действия на ПК — только по подтверждению, выключены по умолчанию.
2. Связь: домашняя Wi-Fi, без выхода в интернет. Туннель/домен — отдельное решение, приложение к нему готово.
3. Агент живёт на этом ПК и доступен с устройств, пока ПК включён.

## Этапы (каждый — зелёные тесты + коммит в ветке `v2-agent-app`)

### 1. Ветка и удаление
- `git switch -c v2-agent-app`; удалить списки выше; `config.py` сократить до путей и UTF-8; `requirements.txt` по факту.
- `alontito/skills.py`: убрать `AlontitoBot` (зрение), оставить `SkillResult`.
- Новый `tests/test_no_roblox.py`: в коде и активах нет `roblox`, `placeId`, `SendInput`, `3623096087`. Обновить `test_alontito`, `test_pet_logic`, `test_pult`, `test_omni_opus5`.

### 2. Разъём мозга (`alontito/model.py`) — главное новое
- Провайдер **`own`** — ваш мозг: в `config/alontito_brain.json` адрес локального эндпоинта (HTTP, формат Ollama/OpenAI-совместимый) или путь к весам; интерфейс `chat(messages, on_delta)`. Пока мозг не подключён, агент работает в режиме сбора данных: навыки без модели + честный offline-ответ (никакой чужая модель не подставляется).
- Провайдер **`teacher`** — скачанная Ollama-модель, вызывается **только** из конвейера обучения (генерация обучающих примеров). Из рантайм-чата вызов запрещён тестом: `test_teacher_not_in_runtime`.
- Провайдер `offline` — честный «не знаю» из статуса, без выдумок.

### 3. Контуры обучения (для вашего мозга)
- Рантайм: ответ агента → `LearningEngine.add_example` (pending) → подтверждение ✓ с устройства (`approve`) → `export_approved` в `data/curated_training.jsonl`.
- Учитель: скрипт `tools/teacher_generate.py` — по одобренным примерам и пробелам (вопросы без ответов) генерирует синтетические пары промпт→ответ; они попадают в датасет только через тот же гейт одобрения.
- Обучение: `training/train_lora.py` (ручной, CUDA) → `compare_and_promote` (прирост ≥ 0.02 на `regression_suite`) → ваш мозг подключается в провайдер `own`. Всё локально.
- Тесты с фейковой моделью: маршрут навыков, воспоминания `recall`+`find_facts` в промпте, offline не выдумывает, кандидат без ✓ не становится фактом, учитель недоступен из чата.

### 4. Агент и навыки (`alontito/agent.py`)
- `Agent.answer(text, device)`: явные навыки без модели («запомни: …», «напомни …», «статус», «что мы решали про …») → иначе `ExperienceMemory.recall()` + `Memory.find_facts()` в промпт → провайдер `own`; после ответа — `add_experience`, чат, факты-кандидаты (только после ✓ с устройства; сказанное напрямую — сразу факт, источник «пользователь»).

### 5. Напоминания и входящие
- `alontito/automations.py`: парсер («через 20 минут», «завтра в 9:00», «каждый день / будни / понедельник в ЧЧ:ММ»), `due(now)`, атомарное `data/alontito/automations.json`.
- `alontito/inbox.py`: `data/alontito/inbox/` + `inbox.jsonl`; text/voice/image/file; лимиты. Тесты на замороженных часах.

### 6. Сервер (`pult/server.py`)
- Убрать игровое (`run_skill`, кадр, телеметрия силы, `games.registry`).
- **Устройства:** `data/alontito/devices.json`; сопряжение — 6-значный код на 5 минут с ПК → телефон вводит → токен устройства; лимит попыток; отзыв.
- Поток: дельты мозга в существующий SSE (`chat_delta`/`chat_done`), напоминание → `notification` всем устройствам.
- Эндпоинты: `GET /api/state`; `POST /api/chat`; `/api/automations` (+ run); `/api/inbox` (+ process); `/api/facts` (+ кандидаты ✓/✗); `POST /api/pairing-code`, `/api/pair`; `/api/journal`, `/api/events`; `/pet/*`. Слушает `0.0.0.0` (кадра экрана больше нет).
- Голос: браузер пишет WAV 16 кГц → Vosk (если установлен) → чат, иначе «не расшифровано». Фото сохраняется; понимание — только когда ваш мозг с зрением будет подключён.

### 7. Приложение (`pult/static/`)
- Экраны: **Чат** (стриминг, вложения, голосовое), **Память** (факты со статусами, кандидаты ✓/✗, поиск), **Автоматизации**, **Входящие**, **Журнал**, **Алонтито** (3D), **Настройки** (сопряжение, тема, статус мозга, обучение). Убрать силу/график/кадр/игры.
- PWA: `manifest.webmanifest`, `sw.js` (кэш оболочки), иконки 192/512 + maskable, `apple-touch-icon`.
- Персонаж: `pet3d/` раздаёт сервер, `<iframe>` + `postMessage`; лёгкий режим без портала 42 МБ на телефоне; реакции: думает → `think`, ответил → `nod`, напоминание → `point`, приветствие → `wave`. Активность «Roblox» убрать (`roblox_watch_back` → `watch_back`).
- Дизайн-контракт `test_pult.py` под 7 экранов.

### 8. Запуск, терминал, MCP, документы
- `Alontito.bat` → лаунчер: сервер + окно приложения. `Alontito_Terminal.bat` — терминал без игровых команд. Рабочий стол: убрать Roblox-активности персонажа.
- `mcp_server.py`: `get_status`, `get_agent_memory`, `search_experience`, `record_learned_fact`, `create_reminder`; починить `python -m` запуск и сигнатуру `add_fact`. Внешний ИИ читает память агента.
- README, CHANGELOG (2.0.0), BUILDER_LOG (E-024), `MODEL.md`, `pult/docs/`.

### 9. Действия на ПК (выключено по умолчанию)
- `alontito/pc_actions.py`: белый список `open_url`, `open_path`, `list_dir`, `read_text`; модель предлагает → подтверждение с любого устройства → выполнение → журнал. Включается в Настройках.

### 10. Учитель для обучения (единственная загрузка модели)
- Проверить железо → `ollama pull` одной модели (7B при 16+ ГБ, иначе 3B) — **только** для `tools/teacher_generate.py`. В рантайм-чат она не вызывается (закреплено тестом).
