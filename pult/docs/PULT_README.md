# Alontito Pult — веб-пульт companion'а (телефон + ПК)

Zero-dependency пульт: только стандартная библиотека Python (http.server, SSE,
urllib, sqlite3). Чат отвечает через локальную Ollama; если она не запущена —
работает автономный ответчик по статусу.

**Алонтито не играет за пользователя** (решение от 2026-11-24). Пульт только
читает: статус, наблюдение сцены, журнал, память, база знаний и чат. Кнопок
«подход», «закрыть диалог», «пауза агента» здесь нет — ввод в игру отключён на
уровне `InputController` (`config.GAME_INPUT_ENABLED = False`).

## Запуск

Из корня репозитория:

```
python pult/server.py
```

или двойной клик по `Pult.bat`.

При первом запуске генерируется токен и пишется в `pult/pult_config.json`
(файл в `.gitignore` — токен не должен попадать в репозиторий). Консоль
показывает готовую ссылку:

- **На ПК:** http://127.0.0.1:8787/?token=`<TOKEN>`

Токен сохраняется в браузере (localStorage) и убирается из адресной строки.
Страница-оболочка открывается без токена, но все данные — только с ним.

## Доступ с телефона

По умолчанию пульт слушает только `127.0.0.1`: он показывает кадр экрана и
историю чата, поэтому локальную сеть открывают явным решением. В
`pult/pult_config.json` задайте:

```json
{"host": "0.0.0.0", "port": 8787}
```

и перезапустите пульт — консоль покажет ссылку вида
http://`<IP-ПК>`:8787/?token=`<TOKEN>` (одна Wi-Fi сеть). Токен передаётся по
обычному HTTP: используйте только в доверенной сети.

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Панель** | Сила/гемы/окно/сессии, график прироста, свежий кадр окна игры (не старше 30 с), кнопки «Проверка HUD» и «Наблюдать сцену» |
| **Чат** | Диалог с Алонтито (Ollama) + быстрые команды; намерение «статус / что видишь» выполняет чтение сцены |
| **Терминал** | Живой поток журналов (`journal.jsonl`, `eye_journal.log`, `telemetry.log`) через SSE |
| **Память** | Статистика навыков, счётчики фактов/вопросов, история чата пульта |
| **Знания** | Read-only просмотр клона `alontito-knowledge` (уроки, факты, навыки) |

## Безопасность

- Сервер слушает `127.0.0.1`; доступ из локальной сети — только через `host`
  в конфиге.
- Токен: `secrets.token_urlsafe(12)`, сравнение постоянным по времени.
- Единственный эндпоинт действий `/api/action` принимает только `health` и
  `observe`. Эндпоинта команд автономному циклу нет.
- Тело запроса ограничено 64 КБ, сообщение чата — 2000 символов.
- Заголовки `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`.

## Чат: подключение Ollama

По умолчанию: `http://127.0.0.1:11434`, модель `qwen2.5:7b-instruct`
(как в `config_omni.json`). Меняется в `pult_config.json`:

```json
{"ollama_url": "http://127.0.0.1:11434", "ollama_model": "alontito-opus:latest"}
```

История чата — в `data/pult_chat.sqlite3`.

## Структура

```
pult/
  server.py        # веб-сервер, REST, SSE, чат, статика
  static/          # index.html, style.css, app.js (mobile-first)
  pult_config.json # создаётся автоматически (host/port/token/ollama), в .gitignore
```

## Что проверено и чем

`python -m unittest tests.test_pult` поднимает сервер на свободном порту
loopback и проверяет: отказ без токена (401), отказ на `train`/`close_dialog`
(403), отсутствие `/api/agent` (404), лимит тела (413), не-ASCII токен
(401, без падения), чтение статуса и журнала. Живой просмотр из браузера и
доступ с телефона не проверялись — см. BUILDER_LOG.md (E-022).
