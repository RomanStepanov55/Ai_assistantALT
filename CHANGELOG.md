# Изменения — SkillBotRobloxMuscle

## v2.0.0 — 2026-11-27

**Тема: Alontito — личный ИИ-агент на любых устройствах. Игровой слой удалён
целиком; мозг — свой, локальный; обучение — с человеческим гейтом.**

### Решение пользователя (27.11.2026): Roblox — ни запуска, ни автоматизации
«Убирай включение роблокса и автоматизацию и скрипт, создай готовое приложение
для всех устройств… который сможет появляться на любом устройстве и работать
на любом устройстве и получать информацию». Правило по модели (тем же днём):
«никакую модель с олламы не ставим — мы делаем своего ии»; скачанная модель
разрешена только учителем для обучения будущего агента.

### Удалено (осталось в истории git, ветка main)
- Запуск игры: `alontito/games_catalog.py` (`roblox://`), приложение
  `alontito-app/` («Control Center», сам запускал игру и держал фокус),
  `AlontitoApp.bat`, `Alontito_Omni.bat`.
- Автоматизация: `agent_actions.py`, драйверы (`eggs/pets/boss/rebirth/
  navigation`), `run_adapter.py`, `run_action.py`, `diag_*.py`,
  `core/{input_controller,window,telemetry}.py`, `brain/{mind,
  decision_maker,capabilities,adapter_policy,learning_memory,watcher}.py`,
  `games/`, Omni-исследователь с исполнителями кликов.
- Зрение HUD: `vision/`, `main.py`, `eye.py`, 5626 отслеживаемых кропов
  HUD, шаблоны глифов, база знаний игры (`knowledge/`, `KNOWLEDGE.md`,
  `SKILL.md`).
- Питомец: активность «Roblox» и клип `roblox_watch_back` (49 клипов).
- Тесты ушедших модулей (6 файлов); новый `tests/test_no_roblox.py` ловит
  возврат любого игрового механизма (токены запуска/ввода/HUD в коде).

### Новое — приложение агента для всех устройств
- **Разъём мозга** `alontito/model.py`: `own` (свой локальный эндпоинт,
  Ollama- или OpenAI-формат, стриминг; конфиг в gitignored
  `config/alontito_brain.json`), `teacher` (только конвейер обучения;
  из чата физически недостижим — `TeacherNotForRuntime`), `offline`
  (честные ответы без модели). Конфиг-лоадер отклоняет облачные адреса.
- **Агент** `alontito/agent.py`: навыки без модели («запомни», «напомни»,
  «статус», «что мы решали про …»), чат со своим мозгом с воспоминаниями
  в промпте; каждый ответ мозга — кандидат обучения: ✓ на устройстве
  отправляет в `data/curated_training.jsonl`, ✗ удаляет. Офлайн-ответы
  в датасет не попадают.
- **Напоминания** `alontito/automations.py`: разовые и повторяющие
  («через N минут», «завтра/сегодня в ЧЧ:ММ», «каждый день / по будням /
  каждый <день> в ЧЧ:ММ»); уведомление на все устройства; тесты на
  замороженных часах.
- **Входящие** `alontito/inbox.py`: заметки, голосовые, фото, файлы
  (≤20 МБ, гейты расширений), журнал `index.jsonl`, расшифровка голоса
  офлайн (Vosk, опционально).
- **Сервер приложения** `pult/server.py` (0 зависимостей): мастер-токен +
  токены устройств, сопряжение 6-значным кодом (5 минут, одноразовый,
  глобальный лимит подбора), SSE (стриминг ответа, напоминания, журнал),
  эндпоинты чата/памяти/напоминаний/входящих/обучения/устройств/действий
  на ПК. Слушает `0.0.0.0` — кадра экрана больше нет.
- **Приложение** (7 экранов, тихий дизайн E-023): Чат, Память (✓/✗
  кандидатов), Напоминания, Входящие, Журнал, Алонтито 3D (персонаж в
  iframe через postMessage-мост, лёгкий режим на телефоне), Настройки
  (сопряжение, устройства, статус мозга, уведомления, выгрузка датасета).
  PWA: манифест, service worker (кэш только оболочки), иконки.
- **Действия на ПК** `alontito/pc_actions.py` — выключены по умолчанию:
  белый список (`open_url/open_path/list_dir/read_text`), корни-разрешения,
  предложение → ✓ с устройства → исполнение.
- **Терминал**: свободный текст — разговор с агентом; игровые команды
  удалены. `Alontito.bat` — лаунчер (сервер + окно приложения),
  `Alontito_Terminal.bat` — терминал.
- **MCP**: `get_agent_status`, `get_agent_memory`, `search_experience`,
  `record_learned_fact` (починена сигнатура), `create_reminder`;
  починен запуск `python -m alontito.mcp_server`. Действий в играх нет.
- **Конвейер обучения**: `tools/teacher_generate.py` — учитель генерирует
  примеры, всё сохраняется НЕ одобренным; учитель не может одобрить сам
  себя. Промоушен через `compare_and_promote` (≥ +0.02 без регрессии),
  LoRA вручную на CUDA (`training/train_lora.py`).

## v1.6.0 (приложение) — 2026-11-25

### Решение пользователя (24.11.2026): автоматизация Roblox снята
Причина — юридические риски автоматизации игры. Правило закреплено в коде,
а не только в интерфейсе:

- `config.GAME_INPUT_ENABLED = False`. `InputController` отклоняет каждую
  клавишу, кнопку мыши и движение курсора в `_guard()` — единственной точке,
  где ввод доходит до Windows. Флаг читается при вызове, а не при импорте.
- Наблюдение пассивное: `Watcher.observe()` больше не вызывает
  `ensure_focused()` (ALT, minimize/restore, перетаскивание окна). Так как окно
  больше не поднимается, добавлено доказательство «это игровой кадр» (E-009):
  без плашек бейджей в текущем кадре числа не читаются вовсе — чужое окно
  поверх игры не превращается в «силу 0».
- `main.py` стал входом только для чтения: автономный цикл, adapter-цикл,
  `--test-input/--wheel/--gift/--quests/--rebirth/--adapter` удалены. По
  умолчанию — пассивный наблюдатель. `run_action.py` — только чтение HUD.
  `run_adapter.py` закрывается с объяснением (`build_adapter_stack` остался
  для чтения сцены).
- Терминал: команда `/train` удалена (22 команды). `AlontitoBot.train` и
  `close_dialog` удалены, `ALLOWED_ACTIONS` пуст. «Мозг» (`alontito/brain.py`)
  не планирует ни `train`, ни `close_dialog`: читаемая сцена означает `watch`.
  `/safety` первой строкой называет новое правило.
- MCP: инструмент `execute_safe_action` удалён из списка; запрос получает
  честный отказ. Попутно исправлено: `get_game_vision_state` и
  `capture_screenshot_base64` вызывали несуществующие методы бота — добавлены
  `inspect()` и `capture_frame()`.

### Веб-пульт (`pult/`, из архива `alontito_pult_and_fixes.zip`)

## v1.5.0 (приложение) — 2026-11-22

**Тема: подсистема Omni — непрерывное обучение на локальных моделях.**

- `alontito/omni_mcp_bridge.py`, `telegram_bridge.py`, `voice_assistant.py` —
  MCP-обёртка, Telegram и офлайн-голос (опционально).
- `evaluation/`, `training/`, `config_omni.json`, `README_OMNI_ADDENDUM.md`,

## v1.4.0 — 2026-11-21

**Тема: новый главный экран Алонтито — честная геометрия вместо «примерно ровно».**

### Внешний вид
- Экран переписан на две панели **равной высоты**: логотип 36 колонок + зазор 3 +
  информация. Если текст одной панели короче, другая получает пустые обрамлённые
  строки — нижние рамки совпадают по линии, а не «на глаз».
- Пиксельный знак «AL» 30 клеток в пунктирной рамке; звёзды стоят по внутренним
  углам рамки, а не поверх рисунка.
- Из шапки и экрана убраны эмодзи робота и маскота: они занимают две клетки и
  ломали рамку. Теперь каждый глиф интерфейса — ровно одна клетка.
- Панель информации: градиентный заголовок `АЛОНТИТО v1.4.0`, слоган, линейка,
  короткое описание, строка `◈ open-source ⌘ MIT ♥ Alontito Dev Team`, чипы
  состояния `○ MCP · выкл` и `3D ○ выкл`, строки «игра» и «память».
- Ниже 94 колонок панели складываются вертикально, а не наезжают друг на друга.
