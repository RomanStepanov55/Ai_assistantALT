# Постепенное обучение весов (опционально)

Алонтито учится на двух разных уровнях:

1. **Немедленно и безопасно:** долговременная память, поиск похожего опыта, проверенные уроки и обратная связь. Это не меняет веса базовой модели.
2. **Периодически:** отдельное LoRA-дообучение адаптера на одобренном датасете. Оно запускается вручную, требует CUDA GPU и не заменяет базовую модель.

## Путь данных

`задача → ответ → независимая проверка/измерение → обратная связь → одобрение → curated_training.jsonl → офлайн LoRA → регрессионная оценка → ручное продвижение`

Нельзя одобрять пример только потому, что модель сама написала `PASS`. Источники одобрения: явная положительная оценка пользователя либо объективно повторяемая метрика среды. Неудачные и спорные примеры остаются в памяти как опыт, но не попадают в позитивный обучающий датасет.

## Установка

```bash
pip install -r requirements-training.txt
```

## Запуск (вручную)

```bash
python training/train_lora.py --base-model <HF_MODEL_ID_OR_LOCAL_PATH> --dataset data/curated_training.jsonl --output artifacts/alontito-lora --min-examples 30 --epochs 1
```

Скрипт требует CUDA. Он сохраняет только LoRA-адаптер, не перезаписывает базовую модель и не устанавливает адаптер автоматически. Сначала сравните baseline и candidate на одном и том же отложенном наборе задач. Не обучайтесь и не оценивайте на одних и тех же примерах.

## Важные ограничения

- Это не превращает локальную модель в Claude Opus 5 и не гарантирует сопоставимое качество.
- LoRA может ухудшить общие способности (catastrophic forgetting); используйте небольшой learning rate, малое число эпох и holdout-набор.
- Храните версии адаптеров и возвращайтесь к baseline при регрессии.
- Не помещайте секреты, токены, персональные данные и необработанные скриншоты в обучающий корпус.
