# 🛸 ТЗ и Архитектура: Интерактивный 3D-маскот «Алонтито» (Desktop Companion / 3D Pet)

Документ описывает реализацию живого 3D-агента на рабочем столе Windows, связанного с терминалом Alontito и игровым ботом Roblox.

---

## 1. Технический стек: как лучше всего сделать поверх рабочего стола

Для прозрачного оверлея поверх всех окон Windows с поддержкой 3D-графики и взаимодействия мышью наилучший стек:

### Рекомендуемый вариант (Python-нативный):
- **GUI & Overlay**: `PyQt6` / `PySide6` с флагами окна:
  - `Qt.WindowType.FramelessWindowHint` (без рамки)
  - `Qt.WindowType.WindowStaysOnTopHint` (всегда поверх других окон)
  - `Qt.WindowType.SubWindow` или `Qt.WindowType.Tool` (не засоряет панель задач)
  - `setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground, True)` (прозрачный альфа-канал фона).
- **3D-рендерер**:
  - **Вариант А (Легковесный и современный — Рекомендуется)**: `QWebEngineView` + **Three.js** (WebGL). 
    *Плюсы:* Идеально загружает `.gltf` / `.glb` со скелетными анимациями, блендингом морф-таргетов, шейдерами распада (испарение на полигоны/текстуры) и эффектом портала за считанные строки кода. Прозрачный фон WebGL поддерживается из коробки.
  - **Вариант Б (Чистый C++/OpenGL в Python)**: `Panda3D` / `Ursina Engine` с `win32gui` для прозрачности (`WS_EX_LAYERED`).
- **Связь с терминалом**: Межпроцессное взаимодействие (IPC) через `multiprocessing.Queue`, локальный сокет (`localhost:48123`) или **MCP (Model Context Protocol)**.

## 2. Полный список необходимых 3D-анимаций (Rig & Skeletal Animations)

Модель делай в **Blender** в формате **`.glb` / `.gltf`** (единый файл с текстурами и запечёнными анимациями).

| ID анимации | Название | Описание поведения и тайминг |
|---|---|---|
| `idle_neutral` | Спокойное дыхание | Переминается с ноги на ногу, моргает, оглядывается (Loop, 3-4 сек). |
| `walk` | Ходьба | Бодрый шаг по нижней кромке экрана / по заголовкам окон (Loop, 1-1.5 сек). |
| `sit_down` | Сесть | Переход из стойки в положение сидя (0.8 сек). |
| `sit_idle` | Сидит на панели | Свесил ноги с панели задач, болтает ногами (Loop). |
| `drag_panic` | Паника при перетаскивании | **Когда пользователь схватил и тащит мышкой**: персонаж болтается в воздухе, смешно машет руками и ногами, поджимает плечи («левитирует/боится высоты»). |
| `drag_drop` | Приземление | Падает на «пол» (панель задач), пружинит коленями, отряхивается (1.2 сек). |
| `activity_coding` | Программирование | Садится, достаёт мини-голографический терминал/клавиатуру, быстро стучит пальцами. |
| `activity_rubik` | Сборка кубика Рубика | Крутит в руках кубик, чешет затылок, радуется собранной стороне. |
| `activity_thinking` | Задумчивость | Подпирает подбородок рукой, ходит взад-вперёд. |
| `roblox_watch_back` | **Смотрит в экран спиной** | **Режим работы бота**: садится спиной к пользователю, лицом в экран. Голова следит за центром экрана. |
| `portal_reach_in` | Достать вещь из портала | Открывается неоновый фиолетовый портал, робот засовывает туда руку, достаёт предмет (кружку, бургер, отвёртку), портал схлопывается. |
| `portal_eat_drink` | Перекус у экрана | Пьёт напиток через трубочку / ест снек, не отрывая взгляда от игры. |
| `head_scratch` | Чешет затылок | Реакция на сложную ситуацию в игре или паузу. |
| `cheer_win` | Празднование победы | Подпрыгивает, показывает 👍, машет руками (когда бот получил рекорд силы/ребёрн). |
| `disintegrate` | **Испарение на текстуры** | Спецэффект шейдера: пиксели/треугольники модели разлетаются фиолетовыми искрами в пустоту при скрытии. |

## 3. Механика эмоций и взаимодействия

### 1. Выражение лица (Face Emotes / Eyes Screen)
На лице робота расположен экран:
- **Морф-таргеты (Blendshapes)** или текстурная анимация для глаз:
  - `^_^` — Радость (похвала, победа в Roblox)
  - `O_O` — Испуг (когда его резко подняли курсором мыши)
  - `-_-` — Скука / ожидание
  - `>_<` — Напряжение / концентрация (идёт сложный бой с боссом)
  - `◕_◕` — Спокойное сканирование (дефолт)

### 2. Физика перетаскивания (Drag & Drop)
- При зажатии **ЛКМ** на модели:
  1. Включается анимация `drag_panic`.
  2. Персонаж следует за курсором с небольшой инерцией (пружинящий эффект).
  3. Если отпустить мышь над «полом» (панелью задач): срабатывает гравитация, падение и анимация `drag_drop`.

### 3. Реакция на деятельность человека
Фоновый трекер (`psutil` / Win32 `GetForegroundWindow`):
- Открыт VS Code / PyCharm / Терминал $\rightarrow$ маскот включает анимацию кодинга (`activity_coding`).
- Пользователь бездействует 5 минут $\rightarrow$ маскот достаёт кубик Рубика (`activity_rubik`).
- Запущен **Roblox / Muscle Legends** $\rightarrow$ переходит в боевой режим: поворачивается спиной, достаёт попкорн/газировку из портала и внимательно «мониторит» бой.

## 4. Интеграция с Терминалом Alontito

В консоли добавляется блок команд:
- `/3d on` — Запустить/показать 3D-маскота на экране.
- `/3d off` — Плавное испарение на текстуры и скрытие.
- `/3d mode [free | watch | sit]` — Принудительная смена позы.
- Кнопка в шапке главного экрана: `[3D-Агент: 🟢 на экране / ⚪ скрыт]`.
- При первом запуске бота (если `first_run == True`) терминал выводит интерактивный вопрос:
  ```text
  ✦ Хочешь включить живого 3D-ассистента на рабочем столе? [Y/n]:
  ```
