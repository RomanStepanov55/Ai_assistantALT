# 3D Desktop Pet для Alontito — подключение

`app.py` я не трогал: вся функциональность лежит в отдельных файлах. В `app.py` нужно добавить 4 строки (раздел 3).

## 1. Что в архиве

```
alontito/
  desktop_pet.py        — окно-оверлей (Qt), Three.js-рендер, трекер активности, мозг поведения, PetController
  pet_terminal.py       — команда /3d, вопрос при первом запуске, индикатор статуса для шапки
  pet3d/
    index.html, pet.js  — рендерер: GLTFLoader, клипы, испарение, частицы, портал, реквизит
    animations.json     — 11 клипов (сгенерированы tools/build_pet_clips.py)
    vendor/three/       — three.js r160 (локально, интернет не нужен)
  assets/3d/            — СЮДА положить .glb (см. ниже)
tools/build_pet_clips.py — генератор клипов
tests/test_pet_logic.py  — 34 теста логики (без Qt и GPU)
INTEGRATION_3D.md        — этот файл
```

Распаковывай поверх проекта. Файлов с такими именами у тебя быть не должно — ничего не перезапишется (`__init__.py` в архиве нет).

## 2. Установка

```bash
pip install PyQt6 PyQt6-WebEngine        # или: pip install PySide6
```

Положи модели в `alontito/assets/3d/`:

- `hooded_neon_character_rigged.glb` — персонаж;
- `mini_portal_slim.glb` — портал.

Хэш-префиксы в именах (`3ed061d0-…`) не мешают: ищутся маски `*rigged*.glb` и `*portal*.glb`. Свои пути можно задать в `pet_config.json` (поля `character`, `portal`).

Проверка окружения, до подключения к терминалу:

```bash
python alontito/desktop_pet.py --check        # Qt, модели, three.js, активное окно
python alontito/desktop_pet.py --standalone   # запустить питомца без терминала
```

## 3. Подключение к app.py (4 строки)

```python
from alontito.pet_terminal import pet3d

# 1) при старте, после приветствия / до основного цикла
pet3d.first_run_prompt()   # один раз спросит: «Хочешь включить живого 3D-ассистента на рабочем столе? [Y/n]»
pet3d.autostart()          # если ассистент включён — поднимет его вместе с терминалом

# 2) в цикле обработки ввода, ДО остальных команд
if pet3d.handle_command(user_input):     # /3d on | off | mode … | portal | play | hide | show | scale | check
    continue

# 3) в шапке, рядом со статусом MCP
header += "  " + pet3d.badge()           # вариант под тип вывода — ниже
```

`badge(fmt)` под разные способы вывода:

| Как рисуется шапка | Вызов |
|---|---|
| обычный `print` | `pet3d.badge()` → `3D ● вкл · auto` |
| ANSI-цвета | `pet3d.badge("ansi")` |
| `rich` | `pet3d.badge("rich")` → строка с разметкой `[green]…[/green]` |
| `prompt_toolkit` | `HTML(pet3d.badge("html"))` |

Если шапка перерисовывается не каждый цикл, подпишись на изменения статуса: `pet3d.on_change(lambda st: redraw_header())`.

Статусы индикатора: `○ выкл` · `◌ запуск` · `● вкл · <режим>` · `✖ ошибка`. `badge(verbose=True)` добавляет, что питомец делает сейчас («кодит», «Roblox», «портал»).

Питомец работает в отдельном процессе (Qt должен жить в главном потоке, а терминал блокируется на вводе). При выходе из терминала процесс закрывается сам (`atexit`).

## 4. Команда /3d

| Команда | Что делает |
|---|---|
| `/3d` | статус и справка |
| `/3d on` / `/3d off` | включить / выключить (при выключении персонаж испаряется); выбор сохраняется |
| `/3d mode auto\|free\|still` | режим поведения |
| `/3d portal` | пусть достанет предмет из портала |
| `/3d play <клип>` | показать любую из 11 анимаций |
| `/3d hide` / `/3d show` | испарить / вернуть, не останавливая процесс |
| `/3d scale 0.4–2.5` | размер |
| `/3d check` | диагностика |

Режимы:

- **auto** — реагирует на окна: IDE → `activity_coding`; Roblox → садится спиной к пользователю (`roblox_watch_back`) и каждые 70–140 с лезет в портал (`portal_reach_in` → `portal_eat_drink`). Первый заход в портал — через 12–30 с после того, как сел.
- **free** — окна игнорирует: гуляет, сидит, крутит кубик Рубика, иногда ходит к порталу.
- **still** — спокойный: не гуляет и в портал не ходит.

На самом питомце: ЛКМ + тащить → `drag_panic`, отпустил → падает на нижнюю кромку экрана (над панелью задач) → `drag_drop`. Двойной клик — портал. ПКМ / иконка в трее — меню.

## 5. Настройки (`alontito/pet_config.json`, создаётся сам)

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `enabled`, `asked` | false | включён ли ассистент; задавался ли вопрос |
| `mode` | `"auto"` | режим |
| `scale` | 0.8 | размер (1.0 ≈ 310 px высотой) |
| `fps` | 60 | потолок кадров (в покое сам снижается до 30) |
| `gpu` | `"auto"` | `"software"`, если WebGL даёт чёрный экран |
| `walk_speed` | 95 | скорость ходьбы, px/с |
| `park_x` | 0.82 | где садится кодить / смотреть Roblox (доля ширины экрана) |
| `portal_interval` | [70, 140] | пауза между заходами в портал, с |
| `ide_exes`, `ide_title_hints`, `roblox_exes` | списки | что считать IDE и Roblox — добавляй свои `.exe` |

Если папка проекта недоступна на запись, конфиг пишется в `~/.alontito/pet_config.json`.

## 6. Если что-то не так

| Симптом | Что делать |
|---|---|
| `Не найден PyQt6/PySide6` | `pip install PyQt6 PyQt6-WebEngine` |
| Окно прозрачное, но персонажа нет / чёрный квадрат | `"gpu": "software"` в `pet_config.json`, перезапуск |
| Долго грузится при первом включении | портал весит 42 МБ (большие текстуры). Можно переехать `mini_portal_slim.glb` из `assets/3d/` (без портала питомец работает, просто не ходит к нему) или пережать текстуры в самом glb |
| Нет интернета | не страшно: three.js лежит в `pet3d/vendor/three`. Если папку удалить — возьмётся с CDN, либо `python alontito/desktop_pet.py --download-vendor` |
| Питомец пропадает в полноэкранной игре | эксклюзивный fullscreen скрывает любые оверлеи. Режим «Окно без рамки» в Roblox работает |
| IDE / игра не распознаются | `python alontito/desktop_pet.py --check` покажет `.exe` активного окна; добавь его в `ide_exes` / `roblox_exes` |
| Проверить реакцию без IDE | `ALONTITO_PET_FAKE_ACTIVITY=coding` (или `roblox`) в окружении перед запуском |
| Отладка рендерера | `python alontito/desktop_pet.py --standalone --debug` |

## 7. Про анимации

В `hooded_neon_character_rigged.glb` **нет запечённых анимаций** (0 клипов, только скелет в T-позе), поэтому все 11 клипов — процедурные: `tools/build_pet_clips.py` → `pet3d/animations.json`, при загрузке запекаются в `AnimationClip` по костям твоего рига.

Когда появится glb с настоящими клипами тех же имён (`idle`, `walk`, `sit_idle`, …), они автоматически получат приоритет над процедурными. Править процедурные: открой `build_pet_clips.py`, измени позу или тайминг и запусти `python tools/build_pet_clips.py`.

## 8. Тесты

```bash
python -m unittest tests.test_pet_logic -v     # из корня проекта
```

Покрывают: классификатор окон, мозг поведения (режимы, drag → fall → land, портал, испарение), локальный сервер (MIME, защита от path traversal и DNS-rebinding), протокол родитель ↔ ребёнок, `/3d`, первый запуск и индикатор.
