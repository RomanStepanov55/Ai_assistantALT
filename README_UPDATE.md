# Alontito v5 + пульт: что влито и что изменено

Объединённая запись о двух обновлениях, влитых 23–25.11.2026:

- **`alontito_v5_update.zip`** (16 файлов) — NeuroLab, автономия навыков,
  планировщик, governor, голос, мост пульта, PyQt-пульт, генератор анимаций.
- **`alontito_pult_and_fixes.zip`** (16 файлов) — веб-пульт, реестр игр,
  платформенная абстракция, внешняя калибровка ROI, LFS.

Оба влиты вручную, по одному файлу, с аудитом каждого. **Ни один архив не
распаковывался поверх проекта.** Контекст решения — `BUILDER_LOG.md` (E-022).

## Главное изменение направления

24.11.2026 пользователь снял с Алонтито игру за себя: автоматизация Roblox
убрана, агент стал наблюдателем и консультантом. Всё, что в обновлениях
умело играть, тренировать или кликать, в проект не попало или удалено.

## Веб-пульт: правки относительно архива

Убрано: навыки `train` и `close_dialog`, намерения чата «потренируйся /
закрой диалог / пауза / продолжить», эндпоинт `/api/agent`, кнопки «Подход ×1»,
«Закрыть диалог», «Пауза агента», «Продолжить».

Исправлено и закрыто:

- **Кадр никогда не показывался:** `<img src="/api/frame">` не передавал токен → 404.
- **Кадр искался не там:** в корне репозитория, а пишется в `data/`. Теперь пульт сам сохраняет свежий кадр; старше 30 с — «кадра нет».
- **Слушал `0.0.0.0`:** экран и чат были видны всей локальной сети. Теперь `127.0.0.1`, сеть открывается явно.
- Токен в `pult/pult_config.json` попал бы в git при первом `git add .` — файл в `.gitignore`.
- Тело запроса читалось без лимита; журнал — параметр `n` без проверки; `compare_digest` падал на не-ASCII токене; `innerHTML` для данных из памяти.
- Заголовки `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`; токен убирается из адресной строки.
- Вкладка «Терминал» открывалась пустой — добавлена первичная заливка журнала.

## Как теперь запускать

```
Alontito.bat                       # терминал (22 команды, без /train)
python main.py                     # пассивное наблюдение (журнал сцены)
Pult.bat                           # веб-пульт: http://127.0.0.1:8787/?token=…
```

Тесты — командой из `README.md` (259 тестов). **Не** `unittest discover`.

## Библиотеки v5 без потребителя

`neuro_lab`, `skill_autonomy`, `task_planner`, `resource_governor`,
`panel_bridge`, `voice_chat` покрыты тестами и ни к чему не подключены: они
выбирают действия для агента, который играет, а Алонтито больше не играет.
`ExperimentLab` готов измерять эксперименты пользователя (baseline → замер →
вердикт); бандит и curriculum ждут случая, когда появится, что ранжировать.
