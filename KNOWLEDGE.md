# KNOWLEDGE.md — полная база знаний скилла
## Автономная игра на компьютере: всё, что знает этот агент

Этот документ — «мозг» скилла: суммарный опыт всех сессий разработки бота
Muscle Legends. Главный код: `main.py`, `agent_actions.py`, `vision/`, `brain/`,
`core/`. Правило №1 во всём: **GOLDEN RULE** (см. §1).

## 1. ЗОЛОТОЕ ПРАВИЛО (не обсуждаемое)
- **НИЧЕГО не покупать за реальные деньги. Никаких карт. Никаких биллингов.**
- **Ничего не покупать за валюту, которую покупают за реальные деньги**
  (робуксы; гемы, если они покупаются за робуксы). В этой игре: кнопки
  `+1 Spin 💎48`, `+10 Spins 💎348`, `Collect` у невыполненных квестов
  (`99` гемов), STORE, PACKS, SPOOKY PASS, Auto Lift (геймпасс), BENEFITS,
  CODES — всё это ЗАПРЕЩЕНО.
- Разрешено только бесплатное: тренировки (клики/снаряды/бег), timed gift
  (CLAIM), выполненные квесты, FREE SPIN колеса, ребёрн (бесплатная механика),
  бусты из инвентаря (Use your X? → YES).
- Трейды от других игроков — всегда Reject. Никогда Trade!
- Защита в коде: whitelist ROI (`ALLOWED_CLICK_ROIS`) → whitelist слов кнопок
  (`SAFE_BUTTON_WORDS` + явная блокировка «+N Spin») → popup-защита →
  дельта-мониторинг валюты.

## 2. Почему НЕ Lua (частый вопрос)
- Lua/Luau в Roblox исполняется ТОЛЬКО внутри игры и только из скриптов,
  подписанных разработчиком игры. Игрок физически не может добавить свой скрипт.
- «Запустить свой Lua» = инъекция через эксплойты (Synapse и т.п.) — это
  прямое нарушение ToS, мгновенный бан, активное детектирование античитом
  Hyperion/Byfron, плюс сами инструменты — вредоносная категория ПО.
- Наш путь — внешний агент: скриншоты (глаза) + программный ввод (руки).
  Это «игрок с мышкой»: медленнее инъекции, но без сигнатур для бана.
- Интеллект при этом живёт снаружи на Python — Lua тут не нужен.

## 3. Windows: окна, ввод, координаты (самые дорогие уроки)
### DPI-виртуализация (глава 1 боли)
- При масштабе 150% не-DPI-aware окна (Roblox GDK!) имеют РЕАЛЬНУЮ поверхность
  1280×720, которую DWM растягивает до 1920×1080 ТОЛЬКО визуально. Область
  кликов НЕ растягивается: WindowFromPoint за x>1280 возвращает hwnd=0.
- Следствие: все клики надо считать в координатах РЕАЛЬНОЙ поверхности
  (видимые координаты ÷ масштаб). Захват экрана (ImageGrab) при этом снимает
  РАСТЯНУТЫЙ десктоп — зрение и клики живут в разных системах координат.
- Бот-процесс обязан быть DPI-aware: `SetProcessDpiAwarenessContext(-2)`
  (PER_MONITOR_AWARE_V2) в config.py — иначе захват режет экран и клики плывут.
- Приложение Roblox (меню) тоже DPI-виртуализовано (816×638 → ×1.5).
### Виртуальные рабочие столы
- Окно игры может остаться на другом столе. Лечение: SW_MINIMIZE → SW_RESTORE
  (перетаскивает на текущий стол) → SW_MAXIMIZE (ROIs калиброваны под
  развёрнутое окно) → потом фокус-трюки.
### Лестница фокуса (SetForegroundWindow ограничен)
1. ALT-keydown + SetForegroundWindow + ALT-keyup.
2. min-restore + maximize + повтор.
3. AttachThreadInput к текущему foreground-треду.
4. SwitchToThisWindow.
Проверять результат: GetForegroundWindow() == hwnd.
### Ввод
- Клавиатура: SendInput со SCAN-кодами (DirectX-совместимо) — работает даже
  когда «мышь умерла». **ESC запрещён** (меню Roblox); TAB (лидерборд) запрещён
  пользователем.
- Мышь: SendInput/mouse_event с LLMHF_INJECTED — Roblox GDK МОЖЕТ перестать
  принимать синтетический ввод после телепортов между местами (диагностировано
  дважды). PostMessage (WM_LBUTTONDOWN) игнорируется всегда. mouse_event —
  то же, что SendInput для античита.
- Признак смерти ввода: прирост силы нулевой на нескольких подходах +
  клики не меняют экран → перезапуск игры (самому нельзя — меню игнорирует
  синтетику, нужен человек: Play в приложении Roblox).
- Курсор: перед подходами ставить в безопасный центр (CURSOR_SAFE_POINT),
  иначе клики попадают по HUD.
### Крэши клиента
- Убитый во время апдейта клиент может остаться «зомби»: окно без заголовка
  и с нулевым прямоугольником. Перезапуск: `shell:AppsFolder\<GDK id>`.
  roblox-player: протокол может быть не зарегистрирован.

## 4. Зрение (как видеть игру)
### Захват
- ImageGrab.grab(bbox) снимает то, что ВИДНО сверху: перед чтением поднимать
  игру (ensure_focused). Полный экран в exclusive fullscreen может ломать GDI.
- Кропы ROI в нормализованных координатах клиента (config.ROIS).
### Цифры бейджей = шаблонный ридер (не OCR!)
- WinRT OCR читает тёмное-на-жёлтом, но НЕ читает оранжевое-на-зелёном и
  выдаёт кириллические омоглифы («СИАМ» вместо CLAIM, «81е8к»).
- Шрифт бейджей фиксированный → собрать эталоны глифов (24×32, IoU-скоринг)
  в glyph_templates.npz и матчить формы. Автодообучение: когда OCR-текст
  посимвольно согласен с шаблонным чтением (расхождения только на '?') —
  учить новые глифы. НЕ учиться на мусоре (normalize_ocr_number с фуллматчем).
- Бинаризация адаптивная (Otsu по яркости кадра, v1.2): абсолютные пороги
  (L<110 / R>215) слепли, когда Roblox затемняет сцену за модалкой. Жёлтый
  бейдж — Otsu по L, фиксированный порог остаётся второй независимой попыткой;
  синий — Otsu по L; зелёный — Otsu по `R − G` (оранжевые цифры). Бейдж валюты
  бывает двух видов — определять вариант по медианному цвету (B>G → синий).
- Иконка на плашке (гантель/гем) — не цифра: `TemplateReader._segments()` +
  `_icon_indices()` отбрасывают её ДО классификации, иначе число превращается
  в `'?91.5K'`, а обучение сдвигает выравнивание глифов.
- Кроп второго бейджа расширен до 1.10× — иначе срезался суффикс (`14.0`).
- **Слой глаза** `vision/eye.py`: захват → самокалибровка → кандидаты боксов →
  временной консенсус → OCR-спасение с самообучением → структурированный
  `observe()`. CLI: `python eye.py --health | --frame PNG | --scan | --watch`.
  Отчёт `debug_frames/eye_report.json`, галерея `debug_frames/eye_gallery.html`.
- **«Это игра?» решается по кадру, а не по памяти.** Доказательство — бейджи,
  найденные в ТЕКУЩЕМ кадре (крупная плашка: ≥6% ширины, ≥3% высоты). Сохранённая
  раскладка того же размера — не доказательство: домашняя страница приложения
  Roblox имеет тот же клиентский размер. Кадр без бейджей честно получает статус
  «без HUD игры» (не «нечитаемый счётчик»).
- Анимация бейджа: во время тренировки цифра прокручивается → читать с
  ретраями в широком окне (6×1.2с) + качественный барьер (глифов ≥3-4,
  conf≥0.7) + sanity-гейт ×0.2..×5. На больших силах шаг бейджа 0.1M —
  прирост подхода невидим, верификация только по STATS/лидерборду.
### OCR-инфраструктура
- ПERSISTENT СЕРВЕР (ocr_server.ps1): движок создаётся один раз, обмен по
  stdin/stdout (путь → JSON-строка с боксами). Тёплые чтения 0.2-0.8с
  вместо 2-6с спавна. Холодный старт ~7с → первый таймаут 15с, обычный 5с,
  авто-возрождение через 60с после сбоя (dead_until, не вечный флаг).
- Фоллбек: одноразовый вызов win_ocr.ps1. ПРЕРВАННЫЙ/кривой вывод → ПУСТОТА,
  никогда фейковая линия с (0,0) — она вызывает слепые клики в угол.
- Уникальные имена prep-файлов (uuid) — конкурентные сохранения ломали OCR
  (Errno 22).
- Кириллические омоглифы → CYRILLIC_MAP + difflib fuzzy («СИАМ»→CLAIM).
### Понимание сцены
- Модалки имеют РАЗНЫЕ позиции X-крестика — закрывать через OCR-поиск 'X'.
- Неизвестные модалки фотографировать в debug_frames/learn_me/ (1 раз в
  10 мин) — бот сам документирует то, что не умеет читать.

## 5. Игровые механики Muscle Legends (проверенное + унаследованные заметки)

> **Статус раздела (2026-11-16).** Ниже смешаны два слоя. Всё, что помечено
> `[legacy 06.11]`, — записи ранних сессий: они НЕ перепроверены по корпусу
> 15–16.11 и не имеют подтверждающего кадра или официального источника.
> Текущий реестр фактов со статусами (9 значений) и ссылками на источник —
> `knowledge/sources.csv`; разборы — `knowledge/mechanics.md`,
> `knowledge/rebirth.md`, `knowledge/economy.csv`, `knowledge/pvp.csv`.
> Правило: пустое место не заполняется догадкой — «В доступных источниках не
> подтверждено. Нужна проверка внутри игры».
- Слоты: 1 кулаки, 2 гантели (основной), 3-4 зелья (тратят инвентарь —
  осторожно), 5 аура, 6 стойка, 7 отжимания, 8 приседания, 9 спец, 0 еда.
- Клавиши: E — тренажёр, SPACE — спрыгнуть/прыжок, W — бег.
  Анимация повтора ~0.65с — клики быстрее игнорируются.
- Ловушка тренажёра: клик по центру рядом со снарядом САДИТ на скамью
  (+11/повтор, невидимо) и режим тренажёра глотает UI-клики. Профилактика:
  SPACE + отход ПЕРЕД каждым подходом (smart_lift).
- Тренажёры: искать по E-промпту (W→D→S→A паттерн, ≤8-14с), тип по надписи
  (Treadmill → wait-режим 8с, Bench/Deadlift → клики), выход SPACE.
  Опасность: бездумный W-поиск приводил в зону босса → при 'boss' на экране
  ходить запрещено, трениться на месте.
- Бейджи: жёлтый = сила; второй = конфеты (зелёный) ИЛИ гемы (синий, арены).
- Timed gift (справа, ~3 мин): CLAIM → клеймится ОДНИМ кликом по боксу,
  без модалки, ~+2M гемов. Верификация дельтой гемов.
- Quests: Collect жать ТОЛЬКО у выполненных (прогресс 'N/M', N≥M);
  у невыполненных Collect = пропустить за гемы. Пустые проверки растягивают
  интервал (адаптивно до 15 мин).
- Колесо = ENCHANT PETS: бесплатный спин даёт питомцам бусты (+30% Strength).
  '+1 Spin 💎48' / '+10 Spins 💎348' — ЗАПРЕЩЕНО (валюта за робуксы).
  Клик только по 'FREE SPIN!' (freespin без цифр).
- Ребёрн: сброс силы, постоянный множитель; порог растёт экспоненциально
  (у нас 37 ребёрнов → порог ~78 млрд — далеко). Клик по кнопке REBIRTH →
  нижняя 'Rebirth'-кнопка в модалке → верификация падением силы.
- События на баннере: Brawl (телепорт на арену; после него часто умирает
  ввод), EPIC BOSS, Strongbloxian Games, x2 CANDY CORN, ½ HP.
- Смерть: прогресс не теряется; HUD-бейджи исчезают → детект смерти →
  SPACE + клик по центру до возврата HUD.
- Залы: Starter → Frost (1 реб., 10K) → Mythical (3, 100K, ×4) → Eternal
  (5, 1M) → Legend (10, 5M) → Muscle King (30, 50M).

## 6. Саморазвитие (как бот умнеет)
- Телеметрия → сила/мин на действие → LearningMemory (moving average) →
  ротация тренировок усиливает эффективные упражнения (до +2 слота).
  ВАЖНО (аудит 15.11): `LearningMemory.update_efficiency()` в коде НИКЕМ не
  вызывается — заявленный контур ротации пока не замкнут. Реальная адаптация
  идёт через `CapabilityRegistry` (UCB + измеренная выгода).
- **Достоверность важнее полноты.** Каждая попытка помечается как измеренная или
  нет; `success_rate()` считает только измеренные. «Не смог прочитать бейдж» не
  считается ни успехом, ни провалом (приора 0.5) — иначе агент обучается на шуме.
- Адаптивные интервалы: пустые проверки квестов растягивают их период до
  15 мин; удачные — сбрасывают до 5 мин.
- Неизвестные UI → фото в learn_me/ → человек/агент разбирает и добавляет
  клики. Бот расширяет свою карту игры сам.
- Сессионные отчёты каждые 30 мин в data/reports/ (rates, инсайты).
- Застревание: сила не меняется >15 мин → эскалация: look_around + смена
  позиции + лог.
- Эталоны глифов доучиваются автоматически (полный набор = 0-9 K M .).
- Медиа-журнал: data/eye_journal.log (каждые 10с), scene_state.json,
  telemetry.log, reports/ — оператор-ИИ читает и улучшает стратегию.

## 7. Отладочный плейбук (каждый баг этого проекта и его фикс)
| Симптом | Причина | Фикс |

| Сила стоит, бот «жимает» | сидит на скамье | SPACE+отход до каждого подхода |
| Сила «56.6M» не меняется | шаг бейджа 0.1M | не паниковать; STATS/лидерборд |
| OCR пустой на цветном бейдже | оранжевое на зелёном | шаблонный ридер / R>215 |
| «СИАМ» вместо CLAIM | омоглифы | fuzzy difflib |
| Мусор «256.6M» | анимация счёта | ретраи + sanity-гейт + re-read |
| Клики по углу модалки | фейковая OCR-линия (0,0) | фоллбек = пустота |
| Errno 22 на prep.png | гонка файлов | uuid-имена |
| Агент молчит после старта | окно не найдено (зомби-клиент) | перезапуск через shell:AppsFolder |
| SPIN мог попасть в платное | 'spin' матчился на '+1 Spin 💎48' | только 'freespin' без цифр |
| Сила не читается (None) на каждом подходе | бейдж вне калиброванного ROI (другое окно/DPI/зал) | `locate_badges` — поиск бейджа по цвету в полосе HUD |
| «100K» читается как «166K» | нет шаблона '0', ридер угадывал похожую цифру | порог IoU 0.86 → '?', `tools/harvest_glyphs.py` выучил '0' |
| Обучение «уверено» в бесполезном упражнении | `smart_lift` возвращал +1 при нечитаемом бейдже | три состояния (None/0/>0) + `verified_attempts` |
| '91.K' → сила 91 000 | сегментация потеряла цифру | `is_badge_number` (формат + обязательный суффикс) |
| Русский текст в логе = кракозябры | stdout в ANSI-кодировке при редиректе в файл | UTF-8 reconfigure в config.py |

## 8. Запуск
```bash
python -u main.py            # полный автономный цикл (рекомендуется -u для живого лога)
python main.py --watch       # глаз только читает (журнал сцены)
python main.py --monitor     # HUD-монитор
python run_action.py --hud|--strength|--gift|--quests|--wheel|--rebirth|--observe|--close-modal
```
Файлы состояния: data/telemetry.log, data/eye_journal.log, data/scene_state.json,
data/memory.json, data/reports/, data/glyph_templates.npz.

## 9. Дорожная карта (что ещё умеет делать человек + бот вместе)
- Яйца/питомцы: разовая разведка UI с пользователем → клики в скилл.
- Инвентарь: чистка мусора (осторожно — защита от продажи ценного).
- Боссы: атака, если увидим HP-бар и поймём зону безопасности.
- OCR-сервер: мультипроцессный пул, если понадобится <100мс.
- Робастность ввода: перезапуск игры ботом при смерти ввода (нужно, чтобы
  меню аппа принимало синтетику — пока только человек).
