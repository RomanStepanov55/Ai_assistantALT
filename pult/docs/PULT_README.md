# Alontito — сервер приложения (телефон + планшет + ПК)

Zero-dependency: только стандартная библиотека Python (http.server, SSE,
urllib, sqlite3). Сервер раздаёт PWA-приложение агента на все устройства
домашней сети и связывает их с агентом, живущим на ПК.

**Алонтито не играет за пользователя** (24.11.2026), и с 27.11.2026 в проекте
нет игрового слоя вовсе: ни кадра экрана, ни телеметрии игры, ни эндпоинтов
действий. Мозг — свой, локальный (`alontito/model.py`); никакая сторонняя
модель не отвечает пользователю, учитель (скачанная модель) доступен только
конвейеру обучения.

## Запуск

```bash
python pult/server.py       # или Alontito.bat — сервер + окно приложения
```

- На этом ПК: `http://127.0.0.1:8787/?token=<токен>` — токен печатается при
  старте и хранится в `pult/pult_config.json` (файл в `.gitignore`).
- С телефона/планшета (та же Wi-Fi): `http://<IP-ПК>:8787` → код сопряжения.
- Слушает `0.0.0.0` по умолчанию; вернуть только на ПК — `"host": "127.0.0.1"`
  в `pult/pult_config.json`.

## Сопряжение устройств

1. На ПК (вкладка «Настройки», мастер-токен) — кнопка «Код»: 6 цифр, живут
   5 минут, срабатывают один раз.
2. На новом устройстве: открыть адрес сервера, ввести код и имя — устройство
   получает собственный токен (хранится в его localStorage).
3. Отозвать/вернуть устройство — там же, «Устройства». Подбор кода ограничен:
   не больше 10 попыток ввода в минуту.

## Экраны приложения

| Экран | Что делает |
|---|---|
| Чат | агент: навыки без модели + свой мозг; стриминг ответа, вложения, голосовые |
| Память | факты с 9 статусами; кандидаты обучения с ✓ (в датасет) и ✗ |
| Напоминания | разовые и повторяющие; уведомление на все устройства |
| Входящие | заметки/голос/фото/файлы; расшифровка голоса офлайн (Vosk) |
| Журнал | события агента живым потоком (SSE) |
| Алонтито 3D | персонаж в iframe (мост postMessage ↔ pet.js), лёгкий режим без портала |
| Настройки | сопряжение, устройства, статус мозга, уведомления, выгрузка датасета |

## Безопасность

- Оболочка приложения, иконки, персонаж и `/api/pair` — публичны; всё с
  данными требует мастер-токен или токен устройства (`X-Pult-Token`).
- Токен в localStorage, из URL убирается; сравнение constant-time; лимит тела
  25 МБ (голосовые и фото), чат-сообщение 8000 символов.
- Заголовки `nosniff`, `X-Frame-Options: SAMEORIGIN` (нужен для iframe
  персонажа), `Referrer-Policy: no-referrer`; токен не попадает в логи.
- Действия на ПК (`/api/pc/*`) выключены по умолчанию; включить может только
  мастер-токен, исполнение — только после ✓ устройства, белый список +
  разрешённые корни папок.

## Тесты

`python -m unittest tests.test_pult` — 26 тестов: авторизация и токены,
сопряжение (лимит подбора, отзыв устройств), чат, напоминания, входящие,
обучение, факты, действия на ПК, дизайн-контракт (тихий экран, 7 заголовков,
id разметки ↔ app.js).
